# Personal AI Roadmap

## Vision

Build a private AI workspace that helps users manage knowledge, projects, planning, notes, and daily tasks using AI agents.

The goal is not only to build a chatbot, but a personal AI operating system.

---

# Version Roadmap

Status: Completed

Features:

- Next.js frontend
- FastAPI backend
- Ollama integration
- Qwen3:8B local model
- Basic chat interface
- Local AI response
